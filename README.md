# yardex-assets

Logos publicos referenciados por nuestro emisor de CFDIs (API Multi de Facturama).

Facturama necesita una URL publica .jpg/.jpeg/.png en el campo `LogoUrl`
del payload para embebr el logo en el PDF timbrado. Este repo sirve esos
assets via `raw.githubusercontent.com`.

| Emisor          | Archivo        | URL raw                                                                               |
|-----------------|----------------|---------------------------------------------------------------------------------------|
| YARDCTL         | `yardex.png`   | https://raw.githubusercontent.com/francoh19/yardex-assets/main/yardex.png             |
| HECTOR FRANCO   | `reinsum.jpg`  | https://raw.githubusercontent.com/francoh19/yardex-assets/main/reinsum.jpg            |
